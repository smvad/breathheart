# Changelog

**Read in English:** [CHANGELOG.md](CHANGELOG.md)

## 0.1.1

- Сердцебиение при низком HP теперь пульсирует волнами (нарастание и спад) вместо плоского плато.
- Тяжёлая броня утомляет быстрее: набор нагрузки масштабируется от брони (~1.6x в полном алмазном).
- Задержка дыхания под водой: с погружёнными глазами звуков дыхания нет; сердцебиение растёт по мере опустошения запаса воздуха.
- Страх вардена: сердцебиение учащается рядом с живым варденом (скан близости не чаще раза в секунду, иначе эффекта нет).
- Селф-тест (`/breathheart test`) глушит ambient-звуки на время cues, чтобы не наслаивались.
- Защитные клампы кулдаунов: счётчики шедулера больше не могут залипнуть.
- Экран настроек: кнопка «Сбросить»; JSON конфига несёт поле `version` для будущих миграций.

## 0.1.0

- Первый экспериментальный релиз: дыхание покой / пик / отдышка, сердцебиение при падениях, уроне и низком HP.
- Паника в полёте, только выживание/приключения, экран настроек (клавиша H, `/breathheart config`, кнопка ModMenu), команды `/breathheart debug|test`.
- Процедурные звуки дыхания, CC0-сердцебиение, EN/RU локализация.
